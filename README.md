# KKA Oil Mill – Public Mobile App

This is the first mobile-first public version for KKA Oil Mill.

## Included
- Home page
- Product showcase
- Groundnut, Coconut and Castor Oil sections
- Oil-mill / peanut-processing service section
- About / manufacturer details
- Call and WhatsApp buttons
- Responsive mobile UI
- PWA manifest
- All supplied KKA images copied into `assets/`

## Run
Open `index.html` in a browser, or serve the folder with any simple local web server.

## Android APK
This version is deliberately kept as a simple web project so we can package the same UI into an Android APK using Capacitor/WebView in the next step. No product image has been altered.
